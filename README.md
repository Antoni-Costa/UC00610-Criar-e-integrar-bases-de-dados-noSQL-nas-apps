# 📝 Blog API - MongoDB & Node.js

Este projeto é uma API para um sistema de Blog, desenvolvida como "Trabalho Final" para a UC "Criar e integrar bases de dados NoSQL nas apps".

A API permite gerir publicações (posts) através de operações CRUD, utilizando o MongoDB Atlas como base de dados na nuvem.

---

## 🛠️ Tecnologias Utilizadas

* **Node.js**: Ambiente de execução Javascript.
* **Express**: Framework para o servidor e rotas.
* **MongoDB Atlas**: Base de Dados NoSQL.
* **Mongoose**: ODM (Object Data Modeling) para modelagem de dados.
* **Dotenv**: Gestão de variáveis de ambiente (segurança).
